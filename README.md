# readflow

Webapp serverless personal de biblioteca y lectura.

- `frontend/`: webapp Astro. Ver `frontend/README.md`.
- `infrastructure/`: CDK v2 en TypeScript (Amplify y, más adelante, el backend). Ver `infrastructure/README.md`.
- `docs/adr/`: decisiones de arquitectura.
- `docs/specs/`: contratos entre servicios (modelo de datos).
- `docs/project.md`: canvas y decisiones de arquitectura.
- `docs/consideraciones.md`: consideraciones abiertas.
- `docs/mockup/`: mockup HTML original (referencia).
